# AUTO CHECK

Erste implementierte Version des bestätigten AUTO CHECK Designs.

## Start

```bash
npm install
npm run dev
```

## Enthalten

- Bild 2 als Werkstatt-/Mercedes-Hero
- Bild 3 als AUTO CHECK Logo
- Bild 1 als App-Icon
- Logo fährt 2,5 Sekunden von oben ein
- obere drei Buttons fahren von rechts ein
- untere drei Buttons fahren von links ein
- alle sechs Buttons sind klickbar
- vorbereitete Untermenü-Modalansicht
- responsive Smartphone-Oberfläche

## GitHub

sind bereits als Navigation vorbereitet; die einzelnen Funktionsseiten werden
